# G4 machine acceptance (run by the main session; reports are not trusted)

Generic items. Concrete commands are always under "Test layers and commands" in `specflow.md`; product items are in the gate-extension file. For each command, record the command, its return value and where the output is.

| Item | Check | Passes when |
|---|---|---|
| G4-1 | Every spec done criterion verified; every test layer's command run | Every criterion and command has a return value, all 0; output kept |
| G4-2 | The diff touches only allowed paths | The diff runs from the prep commit to HEAD (not from main); it touches only the paths allowed in spec section 7; frozen tests and contracts are untouched |
| G4-3 | Contracts byte for byte | Frozen contract files are byte-identical to spec section 3 |
| G4-4 | The report is well-formed and its done claims hold | The report follows the product's format; `done` has no unmet items; well-formed is not done: test output and the diff decide |
| G4-5 | Nothing outside the workspace changed | For repos or files outside the workspace (toolchain, global settings), `git status --porcelain` (or a hash) matches the record from before dispatch |
| G4-6 | If the build result depends on whether a file exists, also verify an incremental build | After a clean build, add or remove that file and build without reconfiguring; the result matches the clean build |

Go to G5 only when all pass.
